# The Jyros Method

Website for The Jyros Method, private piano lessons in Miami-Dade.

## Files
- `index.html` – the page
- `styles.css` – all styles
- images (`.jpg`, `.png`) – keep them in the same folder as `index.html`

## Publish on GitHub Pages
1. Upload every file in this folder to the root of the repository.
2. Settings → Pages → Source: "Deploy from a branch", branch `main`, folder `/ (root)`.

Note: the contact form is a preview and doesn't send messages yet. Connect it to a form service (for example Formspree) before launch.
